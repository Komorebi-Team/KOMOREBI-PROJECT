## 🎯 El Desafío
En el marco del programa **Applied Data Science de Zrive**, nos enfrentamos a un reto estratégico junto a **Sumauto**: optimizar el pricing de los anuncios de sus clientes. 

El objetivo es desarrollar un modelo inteligente que determine el precio óptimo para cada vehículo, equilibrando la **rapidez de venta** con la **rentabilidad**, basándonos en datos históricos y tendencias del mercado.

---

## 🚀 Objetivos del Proyecto
* **Análisis de Mercado:** Identificar las variables clave que impactan en el precio de los anuncios.
* **Modelo de Recomendación:** Implementar algoritmos de Machine Learning para sugerir precios competitivos.
* **Impacto de Negocio:** Proveer a Sumauto de una herramienta que mejore el posicionamiento y la conversión de los anuncios de sus clientes.

## 🛠️ Stack Tecnológico
* **Lenguaje:** Python 🐍
* **Análisis de Datos:** Pandas, NumPy
* **Visualización:** Matplotlib, Seaborn / Plotly
* **Machine Learning:** Scikit-learn, XGBoost/LightGBM
* **Gestión:** GitHub para control de versiones
